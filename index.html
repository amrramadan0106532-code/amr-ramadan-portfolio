01 / 06

Fintech & payments

Subscription renewals and online payments for thousands of syndicate members. Payment flows are modeled as explicit states, so a member never ends up charged twice or stuck on a spinner after the gateway returns.

  • Payment gateway checkout with 3-D Secure and deep-link return to the app
  • Renewal & invoice flows as BLoC/Cubit state machines: idle → processing → paid / failed
  • Retries, timeouts and receipt sync handled in the repository layer, not the UI
class RenewalCubit extends Cubit<RenewalState> {
  RenewalCubit(this._payments) : super(const RenewalState.idle());
  final PaymentsRepository _payments;

  Future<void> renew(Invoice invoice) async {
    emit(const RenewalState.processing());
    final result = await _payments.checkout(invoice.id);
    result.fold(
      (failure) => emit(RenewalState.failed(failure)),
      (receipt) => emit(RenewalState.paid(receipt)),
    );
  }
}

Future<Claim> submitClaim(ClaimDraft draft) async {
  final files = await Future.wait(draft.attachments.map(_compressor.compress));
  final form = FormData.fromMap({
    ...draft.toJson(),
    'documents': [
      for (final f in files) await MultipartFile.fromFile(f.path),
    ],
  });
  final res = await _dio.post('/medical/claims', data: form,
      onSendProgress: (sent, total) => _progress.add(sent / total));
  return Claim.fromJson(res.data);
}
03 / 06

AI assistants — text & voice

I led the member-support assistant, which cut response time by 40%. It works as a chat and as a voice conversation: the member speaks, the answer streams back as text and speech.

  • Text-to-text: streamed responses rendered token by token, with chat history and retry
  • Voice-to-voice: record → speech-to-text → AI answer → text-to-speech playback
  • Real-time transport over WebSocket and HTTP streams, with audio session and permission handling on Android & iOS
Stream<String> ask(String message) async* {
  final res = await _dio.post<ResponseBody>(
    '/assistant/chat',
    data: {'message': message},
    options: Options(responseType: ResponseType.stream),
  );
  yield* res.data!.stream
      .cast<List<int>>()
      .transform(utf8.decoder)
      .transform(const LineSplitter());
}
04 / 06

Security

The app holds national IDs, medical records and payment data, so security is part of the architecture, not a checklist at the end.

  • Certificate pinning on every API call
  • Tokens in secure storage (Keychain / Keystore) with refresh handled by a Dio interceptor
  • Encryption of sensitive payloads, role-based access control, obfuscated release builds
// Reject any server whose certificate isn't one of ours
_dio.httpClientAdapter = IOHttpClientAdapter(
  validateCertificate: (cert, host, port) =>
      cert != null &&
      _pins.contains(sha256.convert(cert.der).toString()),
);
_dio.interceptors.add(AuthInterceptor(_secureStorage, _authApi));
